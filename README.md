# מצפן — ניהול כספים אישי

אפליקציה אישית שמתחברת לחשבונות הבנק ולכרטיסי האשראי ועוזרת לשמור על התזרים.

- **התראות תזרים:** למשל "מחר יורדים 1,000 ₪ ויש בעו״ש רק 500 ₪".
- **תחזית יתרה:** לפי חיובים קבועים שזוהו אוטומטית, חיובי אשראי שעוד לא ירדו והוצאה יומית ממוצעת.
- **זיהוי חיובים כפולים:** אותו בית עסק ואותו סכום בהפרש של עד 3 ימים, או אותו מנוי שמשולם בשני כרטיסים. כולל נוסח פנייה לחברת האשראי.
- **הצעות לחיסכון:** האפליקציה מזהה חשבונות סלולר, אינטרנט וטלוויזיה, חשמל, ביטוחים, עמלות ומנויי סטרימינג, ומראה כמה אפשר לחסוך בשנה ואיך.
- **מבצעים עדכניים (אופציונלי):** פעם בשבוע Claude מחפש ברשת את המבצעים הזולים ביותר בקטגוריות שמופיעות אצלך, למשל מסלולי סלולר. לחיפוש נשלח רק שם הקטגוריה, בלי תנועות, שמות או סכומים.
- **חיובים קבועים:** כמה עולה כל מנוי וחיוב קבוע בשנה.
- **כל הבנקים וכל חברות האשראי** שהספרייה [`israeli-bank-scrapers`](https://github.com/eshaham/israeli-bank-scrapers) תומכת בהן. מוסיפים חשבונות מתוך האפליקציה עצמה.

## איך זה בנוי (הכול בחינם)

```
 ┌──────────────┐   כל לילה    ┌──────────────────┐
 │GitHub Actions│ ───────────▶ │ אתרי בנקים/אשראי │
 │ scripts/sync │ ◀─────────── │ (דפדפן אוטומטי)  │
 └──────┬───────┘   תנועות     └──────────────────┘
        │ שמירה
        ▼
 ┌──────────────┐              ┌──────────────────┐
 │  Postgres    │ ◀──────────▶ │ Vercel           │ ◀── הטלפון / המחשב שלך
 │ (Neon חינם)  │              │ public/ + api/   │
 └──────────────┘              └──────────────────┘
```

**למה המשיכה מהבנקים לא רצה על Vercel?** כדי למשוך תנועות צריך להריץ דפדפן Chrome אמיתי, ולפעמים זה לוקח כמה דקות לכל בנק. בפונקציות של Vercel יש מגבלות על גודל ועל זמן ריצה, וזה לא עובד שם באופן יציב. ב־GitHub Actions אין את המגבלות האלה, והוא חינמי לריפו פרטי (2,000 דקות בחודש, והסנכרון צורך בערך 3 דקות ביום).

| תיקייה | תוכן |
|---|---|
| `public/` | הממשק (אפליקציית ווב שאפשר להתקין בטלפון) |
| `api/` | ה־API שרץ כפונקציות של Vercel |
| `lib/` | הלוגיקה: זיהוי כפילויות, תחזית, הצפנה, מסד נתונים |
| `scripts/sync.js` | משיכת התנועות מהבנקים |
| `prototype/` | אב־הטיפוס החזותי הראשון |

## התקנה (פעם אחת, בערך 15 דקות)

1. **מסד נתונים:** פותחים חשבון חינמי ב־[neon.tech](https://neon.tech), יוצרים פרויקט ומעתיקים את ה־connection string (מתחיל ב־`postgres://`). הטבלאות נוצרות אוטומטית.
2. **מפתח הצפנה:** מריצים `npm install` ואז `npm run gen-key` ושומרים את המחרוזת שמתקבלת. **אם המפתח הולך לאיבוד, צריך להזין מחדש את כל הסיסמאות.**
3. **Vercel:** מייבאים את הריפו ב־[vercel.com/new](https://vercel.com/new) ומוסיפים Environment Variables:
   - `DATABASE_URL`: מסעיף 1
   - `MASTER_KEY`: מסעיף 2
   - `APP_PASSWORD`: הסיסמה שתקליד כדי להיכנס לאפליקציה
   - `GH_REPO` = `ElimelechEhrlich/matzpen`, ו־`GH_TOKEN`: לא חובה. בלעדיהם הכפתור "סנכרן עכשיו" לא עובד. ה־token הוא fine-grained token עם הרשאת **Actions: Read and write** לריפו הזה בלבד.
4. **GitHub Actions:** בריפו נכנסים ל־Settings → Secrets and variables → Actions ומוסיפים `DATABASE_URL` ו־`MASTER_KEY` עם אותם ערכים.
5. **מבצעים עדכניים (לא חובה):** יוצרים מפתח API ב־[platform.claude.com](https://platform.claude.com) ומוסיפים אותו ב־GitHub Secrets בשם `ANTHROPIC_API_KEY`. החיפוש רץ כל יום ראשון, ואפשר להפעיל אותו גם ידנית דרך Actions → deals → Run workflow. העלות משוערת בכמה דולרים בחודש (תלוי במספר הקטגוריות). אפשר להגביל אותה ב־Console של Anthropic. בלי המפתח, ההשוואה נעשית מול מחירים מקובלים שמוגדרים מראש ב־`lib/savings.js`.
6. נכנסים לאפליקציה, עוברים ל**חשבונות → חיבור בנק או כרטיס אשראי**, בוחרים ספק וממלאים את פרטי ההתחברות.

## הרצה מקומית

```bash
cp .env.example .env   # ממלאים ערכים
npm install
npm test               # בדיקות הלוגיקה
npm run dev            # http://localhost:3000
npm run sync           # משיכה ידנית מכל החשבונות
```

אפשר לראות את הממשק בלי שרת ובלי חשבונות דרך `/?demo`.

## אבטחה

- פרטי ההתחברות לבנקים מוצפנים ב־AES-256-GCM. המפתח נשמר רק ב־Vercel וב־GitHub Secrets ולא במסד הנתונים, כך שדליפה של מסד הנתונים לבדה לא חושפת סיסמאות.
- המערכת רק קוראת נתונים ולא יכולה לבצע העברות.
- הכניסה לאפליקציה מוגנת בסיסמה, ו־API לא מחזיר את פרטי ההתחברות אף פעם.
- עדיף לפתוח באתר הבנק משתמש לצפייה בלבד, אם הבנק מאפשר את זה.
