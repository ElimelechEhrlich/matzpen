# מצפן — ניהול כספים אישי

אפליקציה אישית (לשימוש פרטי בלבד) שמתחברת לחשבון הבנק ולכרטיסי האשראי, ועוזרת לשמור על התזרים.

## מה היא עושה
- **התראות תזרים** – "מחר יורדים 1,000 ₪ ויש בחשבון 500 ₪", עם הצעות לפתרון.
- **תחזית יתרה ל־30 יום** – לפי חיובים קבועים, חיובי אשראי צפויים והוצאה יומית ממוצעת.
- **זיהוי חיובים כפולים** – אותו בית עסק, אותו סכום, זמן קרוב, או מנוי שמשולם פעמיים.
- **הצעות לחיסכון** – סלולר, ביטוח, עמלות בנק, מנויים.

## מבנה
| תיקייה | תוכן |
|---|---|
| `prototype/` | אב־טיפוס חזותי עם נתוני דוגמה (פותחים את `index.html` בדפדפן) |

## תוכנית עבודה
1. ✅ אב־טיפוס חזותי
2. ⬜ שרת פרטי שמושך תנועות פעם ביום (`israeli-bank-scrapers`), עם שמירת פרטי התחברות מוצפנים
3. ⬜ מנוע בדיקות: חיובים כפולים, תחזית יתרה, זיהוי חיובים קבועים
4. ⬜ חיבור הממשק לנתונים אמיתיים + התקנה כאפליקציה בטלפון (PWA)
5. ⬜ התראות לטלפון
6. ⬜ הצעות חיסכון חכמות בעזרת Claude

## אבטחה
- פרטי ההתחברות לבנק נשמרים מוצפנים ורק אצלך – לעולם לא בריפו.
- האפליקציה קוראת נתונים בלבד ואינה מבצעת העברות.
